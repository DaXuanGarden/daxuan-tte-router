# 研究设计 rationale 模板

每个候选问题只保留一张 rationale，避免把“文献出现过”误写成“本研究可做”或“全球首次”。

```markdown
## 临床决策

- 决策者：
- 人群：
- A 与 B：
- 决策时点和可改变的结局：

## 证据反思

### 直接临床范例
- Citation/URL：
- 它的 population、strategy、T0、outcome、horizon、estimand：
- 可以借鉴的设计：
- 不能迁移的条件：

### 方法学范例
- Citation/URL：
- 它解决的 T0、动态策略、混杂或竞争事件问题：
- 对本项目统计设计的影响：

### 反例或边界
- Citation/URL：
- 该研究/方法为什么不能直接复制：
- 本项目需要的降级或停止条件：

## 候选问题与取舍

- 候选问题：
- 主要 estimand：
- 临床决策价值：
- 数据支持：
- 主要识别假设：
- 主要风险：
- 保留/降级/停止：

## 路由交接

- supporting_skills：
- TTE specialists：
- next_handoff：
- evidence_gaps：
```

文献检索实际执行后，补充数据库、检索式、日期、纳入排除标准和核验状态。没有检索结果时只写待核验，
不要写“未发现研究”。
