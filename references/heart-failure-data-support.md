# 心衰 TTE 数据支持模板

这张表用于在心衰问题进入估计前核对数据能否支持研究设计。`available` 只能在实际字段和时间语义核验后填写。

| 设计对象 | 必须核对的时间/语义 | 状态 | 缺口或降级规则 |
|---|---|---|---|
| 急性心衰表型 | 入院时可识别的诊断、症状、影像或容量负荷证据 | unknown | `+2 L` 单独不能确诊心衰/淤血 |
| 治疗 A/B | 实际给药时间、剂量、停用、补救和拒绝给药记录 | unknown | 只有医嘱没有实际给药时不能声称治疗已执行 |
| T0/WRF 触发 | 肌酐基线、测量时间、阈值首次满足时间、仍符合策略的状态 | unknown | 后续才知道的 WRF 不能回填分组 |
| 策略窗口 | 24 小时或其他窗口内连续剂量/强度和允许切换 | unknown | 无纵向给药覆盖时降级为点策略或停止 |
| 结局 | 死亡、RRT、出院、再入院和目标测量的捕获范围 | unknown | 出院是否阻止住院结局必须写入 estimand |
| 液体平衡/淤血 | 输入、输出、体重、氧合/影像的来源和缺失机制 | unknown | 缺失不能当作正常值 |
| 混杂 | 血压、尿量、氧合、肌酐、利尿反应等治疗前/时变变量 | unknown | 无法按决策时点测量时记录 exchangeability 缺口 |
| 共同支持 | A/B 在临床状态和时间窗内都有可行患者 | unknown | 重叠不足时限制目标人群或停止估计 |

两个心衰问题必须分别填表：利尿启动时机与 WRF 后维持/减量不能共用 T0、策略或救援规则。
